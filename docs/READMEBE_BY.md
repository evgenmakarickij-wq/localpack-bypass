**localpack-bypass** — гэта бясплатны кліенцкі мод з адкрытым зыходным кодам для [Fabric](https://fabricmc.net) і [Minecraft](https://www.minecraft.net) 26.2, які пазбаўляе ад пакут з сервернымі наборамі рэсурсаў. Замест таго каб пры кожным падключэнні зноў спампоўваць той самы набор, ён параўноўвае SHA-1 набору, які дасылае сервер, з ZIP-файламі, што ўжо ляжаць у тэчцы `resourcepacks`. Калі знойдзены адпаведны набор, ён ціха ўключаецца, таму ты далучаешся без запытаў і без чакання. Калі набор новы або змяніўся, адзін экран прапануе спампаваць усе патрэбныя наборы адразу; пасля мод правярае іх, уключае, захоўвае выбар і перазагружае рэсурсы толькі адзін раз. Спампаваныя наборы застаюцца ўключанымі пасля выхаду з сервера, як звычайныя наборы рэсурсаў, а адмова, як і ў звычайнай гульні, адключае цябе ад сервера. Экраны і паведамленні ідуць за мовай гульні; мод прыносіць пераклады для 38 моў (гл. спіс вышэй).

## Як гэта працуе

- **Набор ужо спампаваны:** ён ціха ўключаецца. Ніякіх запытаў, ніякага спампоўвання.
- **Новы або зменены набор:** экран з **Спампаваць усе наборы рэсурсаў**. Наборы захоўваюцца пад `resourcepacks/localpack-<sha1>.zip`, правяраюцца праз SHA-1, уключаюцца і захоўваюцца ў тваіх наладах.
- **Адмовіцца і выйсці:** цябе адключыць ад сервера.
- **Старыя наборы:** раней спампаваныя модам наборы здымаюцца з выбару, калі прыходзіць навейшая версія. Файлы застаюцца на дыску, таму вярнуцца можна імгненна.
- **Нішто не правальваецца ціха:** спампоўванне, якое не ўдалося, кантрольная сума, якая не супала, або файл, які гульня не захацела ўключыць, — пра ўсё паведамляецца на экране або апавяшчэннем, калі экрана няма.

## Налады (Mod Menu)

З усталяваным [Mod Menu](https://modrinth.com/mod/modmenu) мод з'яўляецца ў спісе модаў з уласным экранам наладаў. Гарачых клавіш не дадалі; усё там.

- **Тэчка для спампаваных набораў** — дзе захоўваюцца наборы. Пакіньце яе пустой для ўласнай тэчкі гульні `resourcepacks`. Падыходзіць любая іншая тэчка, у тым ліку на іншым дыску ці агульная тэчка Android; тады наборы дадаткова капіруюцца ў `resourcepacks` перад уключэннем, бо гэта адзіная тэчка, якую чытае сама гульня. Кнопкі адкрываюць тую ці іншую тэчку.
- **Запамінаць серверы, якім вы сказалі «так»** — сервер, з якога вы ўжо бралі наборы, больш не перапытваецца. Адказ таксама запісваецца ва ўласную наладу гульні для кожнага сервера *Серверныя наборы рэсурсаў*, побач з «Спытаць», «Уключана» і «Адключана».
- **Пакідаць наборы з іншых сервераў** — пакіньце ўключаным, каб захаваць наборы, якія ў вас ужо ёсць. Адключыце, каб кожны сервер пачынаў толькі са сваімі наборамі.
- **Чакаць перад запытам** — колькі збіраць рэшту партыі перад з'яўленнем экрана, у мілісекундах ці секундах. Серверы дасылаюць усе свае наборы адразу, таму чаканне ператварае некалькі запытаў у адзін.
- **Здацца праз** і **Спробы** — колькі можа доўжыцца адно спампоўванне і колькі разоў паўтараецца няўдалае. Кантрольная сума, якая не супала, лічыцца няўдачай, бо менавіта так выглядае недаканчаная перадача.
- **Весці запіс** — кожны набор рэсурсаў, які дасылае сервер, запісваецца: які сервер, які адрас, кантрольная сума, памер, што з ім сталася і колькі гэта заняло. Гэта файл на вашым камп'ютары; нікуды нічога не дасылаецца.
- **Спампаваныя наборы** — наборы, якія спампаваў мод, згрупаваныя па серверы, з якога яны прыйшлі, з пазначэннем, ці кожны ўключаны, выключаны або знік з тэчкі. Націсніце на адзін, каб уключыць або выключыць; набор, чый файл знік, можна забыць. **Забыць усё** ачышчае тое, што памятае мод, і ніколі не выдаляе файл набору.
- **Што дасылалі серверы** — сам запіс, найноўшыя зверху, з падрабязнасцямі кожнага запісу.

## Абнаўленні

Раз на дзень мод пытаецца ў GitHub пра [найноўшую версію](https://github.com/evgenmakarickij-wq/localpack-bypass/releases) гэтага рэпазіторыя. Калі яна навейшая за версію, якую ты выкарыстоўваеш, галоўнае меню прапануе яе ўсталяваць. Згода робіць тры рэчы:

1. Новы файл JAR спампоўваецца і **яго SHA-256 правяраецца**, а менавіта супраць маніфеста `update.json`, які публікуецца разам з гэтай версіяй.
2. Стары файл JAR выдаляецца, а новы пераносіцца ў `mods/`.
3. Ты перазапускаеш гульню.

У Windows немагчыма выдаліць файл JAR, які зараз загружаны, таму кароткі створаны скрыпт чакае закрыцця гульні і выконвае крок 2 за цябе; мод паведаміць табе, калі гэта здарыцца. На Android, Linux і macOS файл JAR, які выконваецца, не заблакаваны і проста замяняецца. Усё, чаго тыкаецца абнаўляльнік, ляжыць у `mods/` і `config/localpack-bypass/`.

Запыт — звычайны ананімны запыт да API GitHub (без токена, без уліковага запісу), у мода няма тэлеметрыі і ўласнага сервера. Прапушчаная версія запомніцца, а `-Dlocalpack.bypass.updateCheck=false` цалкам выключае абнаўленні.

**Агаворка пра нумарацыю версій:** `0.0.1.2026-alpha-build-beta-release` чытаецца як `[0, 0, 1, 2026]`, што стаіць *ніжэй* за ранейшую `0.0.3-beta` (`[0, 0, 3]`). Зборкам з нумарам `0.0.3-beta` або вышэй гэтая версія не будзе прапанавана аўтаматычна, і іх давядзецца замяніць уручную.

## Зборка сваімі рукамі

Мод збіраецца пры кожным push у `main` праз [працоўную працэдуру GitHub Actions](../.github/workflows/build.yml), файл JAR ляжыць сярод артэфактаў запуску. Тэг накшталт `v0.0.3` дадаткова публікуе [версію](https://github.com/evgenmakarickij-wq/localpack-bypass/releases) з файлам JAR і маніфестам `update.json`, які абнаўляльнік у гульні чытае.
